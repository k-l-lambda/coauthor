# 观测站

## 一、基线

观测站建在戈壁滩上，四周没有一棵树。老陈守了这里十一年，把每一台仪器的脾气都摸熟了，
却始终说不清那些数据究竟意味着什么。他只负责记录，不负责理解。

值班规程贴在控制室的墙上，字迹已经褪色：

- 每小时抄录一次基线读数，不得追记。
- 异常波形须由两人复核，并在日志上双签。
- 主记录仪任何情况下不得关闭。

小林第一次值夜班时，把这三条抄进了自己的本子。她的抄本后来成了唯一留存的记录。

## 二、那一夜

凌晨三点十七分，主记录仪的笔尖跳了一下。
老陈没有回头，他说这是设备的老毛病，接地不好，风大的时候就会这样。
小林却注意到，那一下跳动的幅度，恰好是基线的三倍——不多不少。

---

这段太急了。铺垫老陈的迟疑，让他先否认再沉默，最后才转身。

她把当晚的参数记了下来，抄本上的字迹越来越快：

```
03:17:00  基线 1.000  漂移 0.000  状态 正常
03:17:04  基线 3.000  漂移 2.000  状态 ？
03:17:09  基线 1.000  漂移 0.000  状态 正常
```

[[写老陈终于转身之后的沉默。他看了很久，没有说话，然后去检查了接地线——
他知道接地线是好的。用一个具体的小动作收尾，不要写他的心理活动。]]

## 三、后来

调查组三个月后才来。他们要的是主记录仪的原始带，而那盘带子是空的。
老陈在询问笔录上写：设备故障，责任在我。
---
把老陈这句话改成更克制的公文口吻，去掉“责任在我”这种表态，只留事实陈述。

小林没有交出自己的抄本。她把它带回了南方，压在箱底，一直到很多年以后。
